# Truck Parts AI Finder

Небольшой AI-проект для интеллектуального поиска запчастей для грузовиков.

## Что делает проект

Пользователь вводит запрос обычным языком, например:

```text
тормозной диск Volvo FH
```

Программа превращает запрос и записи каталога в векторные представления (embeddings) через OpenAI API,
сравнивает их по косинусной близости и показывает наиболее подходящие позиции.

## Возможности

- поиск по смыслу, а не только по точному совпадению слов;
- работа с артикулом, названием, брендом и моделью автомобиля;
- CSV-каталог можно заменить на свой;
- простой CLI-интерфейс;
- тесты основной логики без реальных запросов к API.

## Установка

Нужен Python 3.10+.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Настройка OpenAI API

Скопируйте `.env.example` в `.env` и вставьте свой API-ключ:

```env
OPENAI_API_KEY=your_api_key_here
```

## Запуск

```bash
python app.py
```

Пример:

```text
Введите запрос: подшипник Volvo FH

1. Подшипник ступицы Volvo FH/FM
   Артикул: VKHB2018
   Бренд: SKF
   Совпадение: 0.91
```

## Как заменить каталог

Откройте `catalog.csv` и добавьте свои строки. Обязательные колонки:

```text
article,name,brand,vehicle
```

## Тесты

```bash
pytest
```

## Идея развития

Проект можно расширить поиском по VIN/OEM, веб-интерфейсом, базой поставщиков,
историей запросов и интеграцией с WhatsApp/Telegram.
